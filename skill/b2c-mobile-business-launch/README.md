# Skill Source Map

This directory has seven responsibilities.

| Directory | Responsibility |
| --- | --- |
| `runtime/` | Typed graph, compilation, scheduling, run state, and runtime adapters |
| `knowledge/` | Bounded domain knowledge loaded by graph context contracts |
| `workspace/` | Reusable business artifacts copied into app repositories |
| `validation/` | Business gates, repository checks, fixtures, and LaunchBench |
| `tooling/` | Renderers, probes, hooks, migrations, and command-line utilities |
| `studio/` | Skill-owned visual studio source, seed state, and generated output |
| `starters/` | Runnable product-archetype foundations |

`SKILL.md` is the runtime entrypoint. `spine.md` is the phase-oriented narrative. Stable graph IDs are identities; filesystem paths are bindings.
